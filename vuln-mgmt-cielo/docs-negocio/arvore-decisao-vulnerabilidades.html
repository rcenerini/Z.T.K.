Árvore de Decisão Automatizável — Priorização de Vulnerabilidades

Modelo SSVC adaptado ao ambiente Cielo · Stack: Veracode · GitHub Enterprise · Orca Security · Tenable

flowchart TD
    A["Novo achado de vulnerabilidade
(Veracode SAST/SCA · GitHub · Orca · Tenable)"] --> B["Agente de Deduplicação/Correlação
(chave: CVE + Ativo + Ambiente)"]
    B --> C{"Ativo é publicamente
exposto?
fonte: Orca (cloud) + Tenable (ASM on-prem)"}

    C -- "Não" --> T1["TRACK
Monitoramento passivo · sem SLA de correção imediata
100% automatizado, zero toque humano"]

    C -- "Sim" --> D{"CVE está no catálogo
KEV da CISA?
fonte: feed KEV/Vulnrichment (novo)"}

    D -- "Não" --> E{"Exploit é automatizável
de ponta a ponta?
fonte: EPSS + Vulnrichment (novo)"}

    E -- "Não" --> F{"Impacto técnico é total
(controle completo do ativo)?"}
    F -- "Não" --> T2["TRACK*
Monitorar + reavaliar se contexto mudar
Automatizado, revisão humana só por exceção"]
    F -- "Sim" --> G1["ATTEND
Fila priorizada · janela 14-60 dias
Triagem humana leve (validação + dono)"]

    E -- "Sim" --> G1

    D -- "Sim" --> H{"Impacto técnico total
E automatizável?"}
    H -- "Não" --> G1

    H -- "Sim" --> I{"Ativo crítico de negócio /
escopo PCI?
fonte: CMDB + tags de contexto de negócio"}

    I -- "Sim" --> ACT1["ACT — Janela de 3 dias
• Mitigação automática imediata (runbook pré-aprovado)
• Triagem forense obrigatória (IR/SOC)
• Escalação executiva automática
• Patch tratado como resposta a incidente"]

    I -- "Não" --> ACT2["ACT — Janela de 14 dias
• Mitigação recomendada (runbook)
• Priorização máxima na fila de engenharia
• Sem escalação executiva automática"]
